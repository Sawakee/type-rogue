# TYPE:ROGUE — ローグライク・タイピングゲーム

ブラウザで遊べるローグライク × タイピングゲーム。迫りくる敵の単語をローマ字でタイプして撃破、フロアを攻略してレリックでビルドを組もう。

**▶ プレイ: https://sawakee.github.io/type-rogue/**

## 遊び方

- ⌨️ 敵の下に表示されたローマ字をタイプして撃破（`shi/si`、`nn/n`、`っ` など表記揺れ対応）
- 🔥 連続ヒットでコンボ & スコア倍率アップ、ミスタイプで途切れる
- 🗝️ フロアクリアごとにレリックを1つ選んで強化（10種、重ね取り可）
- 👑 5フロアごとにボス出現
- 💀 敵がコアに到達するとダメージ。HP 0 でラン終了

`ESC` でポーズ。ベストスコアはブラウザに保存されます。

## 技術

依存ライブラリなしの素の HTML / CSS / JavaScript。描画は Canvas 2D、効果音・BGM はすべて WebAudio でリアルタイム合成。ローマ字判定は全候補列挙方式の自前エンジン。

ローカルで遊ぶには `index.html` をブラウザで開くだけ。
